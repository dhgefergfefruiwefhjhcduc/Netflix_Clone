# Netflix India Landing Page Clone

This project is a front-end clone of the Netflix India landing page, built using only HTML and CSS. It closely mimics the look and feel of the official Netflix homepage, providing a visually engaging and responsive user interface. This project is ideal for those looking to practice or showcase their front-end development skills.

---

## Features

- **Responsive Design:** Adapts to desktop and mobile devices.
- **Custom Assets:** Uses images and icons for logos, backgrounds, and feature highlights.
- **Modern CSS:** Utilizes Flexbox, Google Fonts, and advanced styling for a polished look.
- **Navigation Bar:** Includes Netflix logo, language selection, and sign-in button.
- **Hero Section:** Prominent call-to-action with email input and “Get Started” button.
- **Feature Sections:** Highlights Netflix features with images and videos.
- **FAQ Section:** Styled questions with plus icons, ready for interactivity.
- **Footer:** Contains links and contact information, styled to match Netflix’s branding.

---

## Project Structure

```
netflix/
├── assets/
│   └── [images, logos, videos]
├── index.html
├── style.css
└── README.md
```

- **index.html**: Main HTML file containing the structure of the landing page.
- **style.css**: All styles for layout, colors, fonts, and responsiveness.
- **assets/**: Folder containing images, logos, and any other media used.

---

## How It Works

### index.html

- **Header & Navigation:**  
  Contains the Netflix logo, language selection button, and a sign-in button.
- **Hero Section:**  
  Features a background image, main headline, sub-headline, and an email input with a call-to-action button.
- **Feature Sections:**  
  Multiple sections highlight Netflix features such as watching on TV, downloading shows, streaming everywhere, and creating profiles for kids. Each section uses images and videos for visual appeal.
- **FAQ Section:**  
  Lists frequently asked questions with plus icons, styled for clarity and ready for further interactivity.
- **Footer:**  
  Includes contact information and a grid of useful links, styled to match Netflix’s branding.

### style.css

- **Fonts:**  
  Uses Google Fonts for modern, clean typography.
- **Layout:**  
  Employs Flexbox for responsive and flexible layouts.
- **Colors:**  
  Matches Netflix’s signature dark theme with red accents.
- **Buttons & Inputs:**  
  Styled for consistency and accessibility.
- **Media Queries:**  
  Ensures the page looks good on all devices.

## Getting Started

1. **Clone the repository:**
   ```
   git clone https://github.com/yourusername/netflix-landing-page-clone.git
   ```
2. **Navigate to the project directory:**
   ```
   cd netflix-landing-page-clone
   ```
3. **Open `index.html` in your browser.**
   - No build steps or dependencies required.

---

## Customization

- **Images:** Replace images in the `assets/` folder to update backgrounds or feature images.
- **Colors & Fonts:** Modify `style.css` to change the color scheme or typography.
- **Content:** Edit `index.html` to update text, add new sections, or modify existing ones.
